# desafio-inadimplencia

Analise de inadimplencia habitacional.

## Estrutura do projeto

```text
desafio-inadimplencia/
├── data/
│   ├── raw/          # Dados originais, sem edicao manual
│   ├── interim/      # Bases intermediarias geradas pelo pipeline
│   └── processed/    # Bases finais para modelagem, forecast e reporte
├── notebooks/        # Analises exploratorias e notebook reprodutivel final
├── src/              # Funcoes Python reutilizaveis do pipeline analitico
├── outputs/
│   ├── figures/      # Graficos finais usados no relatorio
│   ├── tables/       # Tabelas, diagnosticos e comparacoes de modelos
│   └── report/       # Relatorio executivo final
├── AGENTS.md         # Instrucoes do projeto para o Codex
├── README.md
└── requirements.txt
```
